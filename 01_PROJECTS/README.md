# Projects

Mỗi dự án BA là một thư mục con `PROJECT_<TÊN>/` chứa:

```
PROJECT_<TÊN>/
├── PROJECT.md        # Tổng quan: mục tiêu, phạm vi, stakeholder
├── REQUIREMENTS.md   # Requirement
├── TASKS.md          # Task/Epic, owner, priority, status
├── SPRINT.md         # Sprint planning, capacity, commitment
├── RISKS.md          # Risk, blocker, dependency
├── DECISIONS.md       # Quyết định của sếp/Product/team
└── CHANGELOG.md       # Lịch sử thay đổi requirement/scope
```

## Dự án hiện có

- `PROJECT_DTI/` — Nền tảng Chuyển đổi số Giáo dục (VNPT-IT/DES), trọng tâm hiện tại: tổng quát hóa khung đánh giá cá nhân TT18 + TT02.

Khi có dự án mới, tạo thư mục `PROJECT_<TÊN>/` theo mẫu trên.
